# DuolingoXdg-lab

# 这是什么

用node.js实现的开启网页多邻国并检测错误回答，在回答错误时发送脉冲信号到郊狼主机

# 需要装的依赖

* ws
* uuid
* qrcode

安装方法：

```cmd
npm i ws
npm i uuid
npm i qrcode
```

如果遇到安装卡住或者等亿年的情况尝试使用代理
例：

npm的源和代理配置文件位置：`C:\Users(用户)\用户名\.npmrc`

```config
registry=https://registry.npmjs.org/
proxy=http://127.0.0.1:7890
https-proxy=http://127.0.0.1:7890
```

> `7890`修改为你的代理软件的端口，我用的clash默认7890
